# Changelog

All notable public changes to DBACHECK2 will be documented here.

## 0.9.0 RC2

Second public Release Candidate focused on SQL Server Full Assessment reliability and report usability.

### Highlights

- SQL Server Full Assessment compatibility routing for Legacy and Modern profiles
- Cleaner normalization of legacy health-check output
- Filtering of DBACHECK2 self-generated implicit-conversion findings
- Improved assessment result readability and triage structure
- Attention Required, Passed, Information, and detailed navigation sections
- Collapsible technical evidence with readable tabular output where possible
- Preserved raw technical evidence for DBA validation
- Portable Windows x64 self-contained distribution
