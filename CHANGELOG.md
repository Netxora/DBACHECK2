# Changelog

All notable public changes to DBACHECK2 will be documented here.

## 0.9.0 RC1

Initial public Release Candidate.

### Highlights

- Multi-engine DBA operations assistant
- SQL Server diagnostic workflows
- PostgreSQL diagnostic support
- Oracle diagnostic foundation
- MySQL and MariaDB support foundation
- Incident operations
- Incident history
- Alert Inbox
- Monitoring integration foundation
- Notification integration foundation
- Subscription and billing infrastructure
- Portable Windows x64 distribution

DBACHECK2 0.9.0 RC1 is intended for controlled POC and validation environments before general availability.
