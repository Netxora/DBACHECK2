# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a potential vulnerability affecting DBACHECK2, contact Netxora privately and include enough information to reproduce and evaluate the issue.

Please avoid including database credentials, API keys, access tokens, connection strings, customer data or other sensitive information in reports.

## Scope

Security reports may include issues affecting:

- DBACHECK2 desktop application
- DBACHECK2 public services
- Authentication or subscription mechanisms
- Database credential handling
- Monitoring and notification integrations
- Distribution and update mechanisms

## Responsible disclosure

Netxora asks researchers to allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
