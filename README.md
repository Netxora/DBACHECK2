# DBACHECK2

**Database Operations Assistant by Netxora+**

DBACHECK2 is a multi-engine database operations assistant designed to help DBAs detect, diagnose, document, and communicate database incidents faster.

## Supported database engines

- Microsoft SQL Server
- Oracle Database
- PostgreSQL
- MySQL
- MariaDB

## What DBACHECK2 does

DBACHECK2 brings operational diagnostics, incident evidence, guided DBA actions, monitoring integrations, and incident documentation into a single desktop application.

Its operational workflow is:

**DETECT -> CORRELATE -> DIAGNOSE -> ACT -> DOCUMENT**

## Capabilities

- Multi-engine database diagnostics
- Blocking and transaction analysis
- Performance diagnostics
- TempDB and transaction log analysis
- Backup, jobs and high-availability checks
- Incident history and evidence
- Monitoring integrations
- Alert Inbox
- Teams, Slack and Discord notification workflows
- Guided DBA actions with human confirmation
